# Política de segurança

## Versões suportadas

O projeto está em fase de MVP. Somente a versão atual da branch `main` recebe correções.

## Relato responsável

Não abra uma issue pública para vulnerabilidades que possam expor contas, dados, credenciais ou regras de autorização. Envie um relato privado ao mantenedor pelo recurso **Report a vulnerability** do GitHub, quando habilitado, ou pelo contato indicado no perfil do autor.

Inclua:

- descrição e impacto;
- passos mínimos para reprodução;
- rota, tabela ou policy envolvida;
- sugestão de correção, se houver.

Nunca inclua chaves reais, senhas ou dados pessoais no relato.

## Escopo prioritário

- bypass de autenticação em Route Handlers ou Server Actions;
- falhas nas políticas RLS;
- acesso ou alteração de projetos de outro usuário;
- exposição de credenciais;
- upload de conteúdo não autorizado.
