# Foto ilustrativa do perfil de exemplo

Asset: `public/partnerships/creators/perfil-exemplo-avatar.webp`.

Gerado com a ferramenta built-in `image_gen`, sem fallback de CLI/API, para o perfil fictício da landing. Não representa um criador confirmado. A interface identifica o perfil e a foto como ilustrativos.

Versão otimizada em WebP, 512 × 512 px, qualidade 85, 20.274 bytes. Banner reutilizado do projeto: `public/ref/hero-opala-ss.webp`. O componente é somente uma demonstração visual; não atribui o selo a perfis reais e não altera dados de usuários.
